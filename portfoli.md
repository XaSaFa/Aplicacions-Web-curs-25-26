# Portfoli

<img width="550" height="335" alt="imatge" src="https://github.com/user-attachments/assets/2b03caa4-b87f-4354-9d53-c32865c820ab" />

Una de les coses més importants a l'hora d'anar a buscar feina a una empresa és **donar a conèixer les nostres capacitats**, i la millor manera de fer-ho és amb una **eina visual** on puguem ensenyar els nostres treballs anteriors, el que es coneix com un portfoli.

El portfoli serveix per:

- Mostrar la nostra informació de contacte.
- Donar a conèixer els projectes que hem fet.
- Donar informació laboral extra.

Hi ha molta gent que incorpora el seu portfoli a la seva web personal, nosaltres farem això aprofitant **Github Webpages**.

## Què necessitem?

### El hosting:

Per tal de poder tenir la nostra pàgina online necessitem un hosting.

Un hosting és un servei d'Internet amb capacitat de mostrar el nostre projecte web, nosaltres utilitzarem github webpages.

Per tal de poder utilitzar aquest servei ens hem de registrar amb un usuari de github a [github.com](https://github.com/).

No utilitzeu el vostre nom real com nom d'uauri i no utilitzeu un nom ofensiu, penseu que tindreu el vostre portfoli i informació vostra alli.

Un cop registrats creareu un repositori que es digui com el vostre nom d'usuari seguit de github.io.

### El programa per actualitzar la web:

Utilitzarem un programa anomenat Github Desktop per tal d'actualitzar la web, és a dir, per treballar la web al nostre ordinador i després pujar la versió actualitzada a github pages.

**Instal·lació a Windows.**

[https://github.com/apps/desktop?ref_product=desktop&ref_type=engagement&ref_style=button](https://github.com/apps/desktop?ref_product=desktop&ref_type=engagement&ref_style=button)

**Instal·lació a Linux.**

[https://gist.github.com/berkorbay/6feda478a00b0432d13f1fc0a50467f1](https://gist.github.com/berkorbay/6feda478a00b0432d13f1fc0a50467f1)

### La web: 

Per a fer el nostre portfoli utilitzarem una **plantilla prefabricada** feta amb HTML, CSS, Javascript i Bootstrap (un framework de creació de webs).

Per que la plantilla no sigui genèrica haurem de modificar-la amb la nostra informació.

La plantilla l'escollirem d'aquí: [https://bootstrapmade.com/bootstrap-portfolio-templates/](https://bootstrapmade.com/bootstrap-portfolio-templates/).

Un cop descarreguem la plantilla la descomprimim a Documents i l'editarem utilitzant Visual Studio Code.

### Visual Studio Code:

Utilitzarem aquest IDE per modificar la plantilla i adaptar-la al nostre portfoli particular.
